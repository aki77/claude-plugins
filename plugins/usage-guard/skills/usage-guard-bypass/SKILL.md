ユーザーが指定した期間で usage-guard のバイパスを設定し、スクリプトの出力をそのまま提示する（要約・整形はしない）。

## 引数の扱い（重要・セキュリティ）

ユーザー入力を**そのままシェルコマンドに埋め込まないこと**。次の許可リストに完全一致するものだけを引数として渡す。

- `off` — バイパス解除
- `reset` — 5時間枠のリセットまで
- `<数字>` — 分として解釈（例: `90`）
- `<数字>m` — 分（例: `30m`）
- `<数字>h` — 時間（例: `2h`）

判断の手順:

1. ユーザーの指定が上記のいずれかに**完全一致**するなら、その値をそのまま使う。
2. 引数が省略されていれば `30m` を使う。
3. 一致しない場合（余分な記号・空白・引用符・`;` `|` `&` `$` `` ` `` などを含む、複数語である、等）は、
   **コマンドを実行せず**、許可された形式を示してユーザーに言い直してもらう。
   入力を「解釈して近い値に直す」ことはしない。

## 実行

`<期間>` は上の手順で確定した許可リスト内の値に置き換える（ユーザー入力の文字列を貼り付けるのではなく、検証済みの値を書く）。

```bash
CLAUDE_PLUGIN_DATA="${CLAUDE_PLUGIN_DATA}" node ${CLAUDE_PLUGIN_ROOT}/skills/usage-guard-bypass/scripts/bypass.mjs <期間>
```
